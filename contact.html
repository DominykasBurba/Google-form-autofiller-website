Support

Need help with Google Form Auto Filler?

The Chrome Web Store listing is the best place to report an issue, leave feedback, or check the current extension version.

When reporting an issue

  • Include the extension version and Chrome version.
  • Describe the Google Form question type: text, radio, checkbox, dropdown, grid, or scale.
  • Explain the question text and answer format you used.
  • Remove private answers and personal information from screenshots.
