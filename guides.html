Google Forms tutorials

Learn to autofill every common Google Forms question type.

Save question-and-answer pairs once, then use Google Form Auto Filler to reuse them for repeat data entry, form testing, and surveys.

Fill your first form

Start with a saved question and answer, then reuse it on a matching Google Form.

  1. Open a Google Form and click the extension icon to open the drawer.
  2. Select Add Field. Enter the question as it appears on the form, without the leading number or required asterisk.
  3. Enter your answer and select Save & Fill. Review the filled answers before submitting the form yourself.

Multiple choice, dropdowns, and linear scales

Choose a single option by its position or by its exact label.

  1. Enter the question text, then use a number such as 2 to select the second option.
  2. You can also enter the exact option label. Use a position if labels are duplicated or numeric.
  3. Skip the dropdown placeholder when counting. On a scale that starts at zero, 1 still selects the first option.

Checkboxes and grids

Select several options or save a separate answer for each row of a grid question.

  1. For checkboxes, separate option positions or labels with commas. Use positions for labels containing commas.
  2. For grids, enter each row label as its own saved question. Use one column for a multiple-choice grid or several columns for a checkbox grid.
  3. Check the form's rules after filling. A required grid may need an answer in every row.

Random answers for testing

Create reusable lists of sample values for repeatable Google Forms testing.

  1. Open Random Fill in the drawer and select Add List.
  2. Name the list and enter comma-separated values, then select Save Lists.
  3. Use @random(cities) as an answer for a list named cities. Save & Fill chooses a value and reuses it until you save again.
